# Timbre AI

Timbre shows how much of your voice is public online and helps you reduce it, before a voice-clone scammer finds it.

This repo is the **v0 website + app UI with a mocked backend**. See [`BUILD_REPORT.md`](BUILD_REPORT.md) for how to run it, the route map, what is mocked, and how to swap in the real backend. Product docs live in [`.plans/`](.plans).

```bash
npm install
npm run dev
```
